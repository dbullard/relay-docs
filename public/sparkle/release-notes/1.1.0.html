Relay 1.1.0

A BIG UPDATE

New

  • Added new NDI support with video monitoring capabilities for Relay dashboards.
  • Added a new Shure Summary module for simplified monitoring of wireless microphones and IEM systems.
  • Added a new DAW Transport module for monitoring and controlling supported DAW transport workflows.
  • Added a dedicated Roster Team Assignments module to use with new Roster types
  • New Planning Center Team Assignment module that will allow for more formatting of teams and assignments in addtion to assigning stored mics, IEMs, and equipment from the new Equipment Roster type.
  • Added new Variable node in Automation view so you can store custom variables or inbound OSC strings as reference-able text via the new variable input button in the Text Module.
  • Added new Vista 3 Node in Automation view to convert Planning Center rundowns as cuelists via importable .csv files in Vista software.
  • Added new if/then logic node so you can control the flow of your automations.
  • Continued development work toward future iPad support.

Improved

  • Improved Relay account handling, licensing, entitlement refresh, and App Store synchronization. Link your subscription to Relay via your purchase email and use that to license instead of memorizing license keys.
  • Improved dedicated Roster editing view accessible from the toolbar. 3 new Roster types that will allow you to use your rosters across all tabs.
  • Improved dashboard editing, canvas behavior, tile resizing, and Live Mode performance.
  • Improved Automation View performance and handling for larger graphs and complex workflows.
  • Improved Planning Center assignments with richer wireless device mapping and roster workflows.
  • Improved Shure wireless monitoring with enhanced RF, battery, mute, audio, and transmitter reporting.
  • Improved NDI performance, reconnect behavior, diagnostics, settings, and video pipeline efficiency.
  • Reworked External Controls with a combined MIDI and OSC monitor view, live activity tracking, and setup guidance.
  • Expanded diagnostics with additional performance, dashboard, automation, and runtime information.

Fixed

  • Fixed multiple Planning Center stability, refresh, and authentication issues.
  • Fixed dashboard rendering, graph behavior, and Live Mode performance issues.
  • Fixed automation view rendering and efficiency issues.
  • Fixed several crash paths and improved overall application stability.
  • Improved security handling across integrations and credential storage.
