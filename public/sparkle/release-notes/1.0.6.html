Relay 1.0.6

New

  • Tab schedules
    • Added tab schedules so tabs can automatically switch based on date and time.
    • Useful for teams with multiple events or services on the same day.
    • Open Tab Settings > Schedule to set schedule rules.
  • Keyboard shortcuts
    • Added quick keys to navigate tabs more easily.
    • Added a new option in the Help menu to see all keyboard shortcuts available in Relay.

Fixed

  • Fixed a bug where dashboards with many Shure modules could freeze or crash after running for a while in Live Mode.
  • Added a possible fix for a Text module bug that caused random characters and line breaks.
  • Fixed UI issues.
