Relay 1.0.7

New

  • Planning Center module updates
    • Added more rundown columns, including song and item details and notes sections.
    • Added a new Team Assignments UI to make it easier to sort teams and see who is scheduled for each position, service time, and status.
  • Tab schedules
    • Added tab schedules so tabs can automatically switch based on date and time.
    • Useful for teams with multiple events or services on the same day.
    • Open Tab Settings > Schedule to set schedule rules.

Fixed

  • Fixed bugs that could select modules and nodes while working in different views, causing unwanted editing or deletion.
  • Fixed Text module issues.
  • Improved data fetching performance.
  • Fixed UI issues.

Notes

  • Tab schedules are a Relay Pro feature because the free version supports one tab.
