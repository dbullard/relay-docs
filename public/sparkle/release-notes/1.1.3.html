Relay 1.1.3

What's New in Relay

New Features

  • Real-Time Analyzer (RTA): View frequency bands of your audio inputs in real-time with new bar and filled-curve display modes and peak-hold capabilities.
  • Spectrograph: A new scrolling waterfall view for visualizing audio frequency distributions over time.
  • Global Audio Settings: Manage all your audio inputs, transcription configurations, and per-input SPL calibration centrally.
  • Advanced Transcription Controls: Fine-tune auto-gain sensitivity, apply word substitutions, and enable profanity masking on a per-input basis.
  • SPL Input Logging: Record SPL data for specific inputs directly to CSV files, complete with a pulsing green indicator on your tiles when recording is active.

Improvements

  • Shure Overview Hub: A new centralized polling system for Shure wireless devices featuring dynamic METER_RATE tiers for greater efficiency.
  • Upgraded dashboard tile resizing with smart guides, a floating size HUD, and a consolidated resize layout for smoother editing.
  • Audio level calculations now use proper LAeq energy averaging for significantly greater accuracy.
  • Optimized performance by skipping redundant polling for METER_RATE-capable Shure wireless microphones.
  • Settings changes for audio inputs now take effect immediately without requiring restarts.
  • Existing module-specific transcription settings now automatically migrate to the new global system on launch.

Bug Fixes

  • Fixed a crash related to the FFT calculations when selecting an input for the RTA or Spectrograph.
  • Corrected C-A audio level calculations and removed the double application of calibration offsets in the dB reader.
  • Fixed an issue where SPL Level logging could silently fail when saving to protected folders like Desktop, Documents, or Downloads. Relay will now correctly show an error banner requesting folder permissions.
  • Reduced unnecessary error reporting and diagnostics from Shure wireless connections.
