Relay 1.2.1 (Beta)

Shure Updates

  • Fixed Shure Overview presence-refresh gaps for channels that don't have an open tile.
  • Corrected Axient presence and RF accuracy, switched ANX4 to default to TCP, and fixed a polling starvation issue in Overview.
  • Improved AD4Q and Axient RF meter reliability, fixed a battery display gap, and polished the Shure Overview UX.
  • Stuck Shure UDP and TCP connections in a waiting state now escalate into the automatic reconnect path.

UI & Bug Fixes

  • Added a Close Home button on the launch screen to dismiss it back to the dashboard without restarting the app.
  • What's New entries are now gated by installed app version so you only see what applies to your build.
