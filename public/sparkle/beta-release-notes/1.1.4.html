Relay 1.1.4 (build 55) Beta

Relay 1.1.4 (Beta) — Build 55

New

  • Standard console actions. Automation can now send common audio-console commands like scene recall, channel mute, level, and pan on supported X32/M32 and Yamaha DM7/Rivage systems.
  • More beta audio console integrations. Added Behringer WING support with network discovery and Avid VENUE S6L support with VENUE OSC connection settings.

Improved

  • Smoother canvas editing. Pan, zoom, resize, distribute, and dragged-tile rendering are more stable, with tab and tile edits resolved by stable identities instead of stale positions.
  • Better device recovery and setup. Shure devices now show reconnecting status and recover more cleanly, dead console connections are rebuilt before sending, and external device type lists are alphabetized for easier scanning.

Fixed

  • Fixed several strict-concurrency and transport-state issues across helper, OSC, shape, and integration code paths.
  • Fixed remaining tab mutations that could target a stale position instead of the intended tab.
  • Fixed Sennheiser wireless using a different category icon than Shure wireless in external device settings.

Relay 1.1.4 (Beta) — Build 54

Improved

  • "Auto" transport mode for ANX4/ADTD/ADTQ now actually auto-detects. Previously Auto silently always used the older connection method — you had to manually pick "TCP Only" to get Build 53's improvements. Now Auto briefly checks whether your device supports the newer protocol and switches automatically.

Fixed

  • Fixed a bug where, once Auto had settled on the newer connection type, Relay would needlessly disconnect and re-check it on every reconnect attempt.

Relay 1.1.4 (Beta) — Builds 49–53

Highlights

  • Expanded Shure support. Added ANX4, ADTD, and ADTQ support with TCP control, automatic licensed channel-count detection, RSSI fixes, and correct licensed channel counts across automation, Shure Summary, Planning Center team assignments, and tile editing.
  • Synced Tabs. Keep a tab live and editable across your devices on the same network — different from Mirroring, which is view-only. Devices must approve each other before syncing or mirroring can start.
  • Reworked Button module with more buttons per module and a much bigger icon library.
  • Shure Summary module gained card/list display, sizes, per-channel person names, and a choice of signal light/meter/hidden for live audio activity.
  • Tab Settings General page for Canvas Size, Sync This Tab, and a live list of who's viewing.
  • CSV/Excel roster import and opt-in diagnostics, plus multi-select canvas tools and broader crash-reporting controls.
  • ProPresenter State trigger (beta) for automation, a distinct Paused state for DAW Transport, and a Reconnect option for sync devices that fail authentication.
  • Broad reliability fixes across icon search, device discovery/reconnect, Sync/Mirror settings, dashboard guides, and numeric settings fields.
