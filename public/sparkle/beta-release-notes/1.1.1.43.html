Relay 1.1.1 (build 43) Beta

What's New

Home Screen & Launch Experience

  • New home screen with a sidebar, recent files grid, and canvas size picker when creating a new dashboard
  • Startup file — right-click any file to pin it as always-open on launch; bypasses the home screen and save dialog automatically. Pinned files show a blue pin badge in the grid

Auto-Save

  • Saving/Saved status indicator in the toolbar
  • Auto-save now enabled by default for files with a known save location
  • First-time auto-save users see a one-time modal with an inline toggle to disable it

Canvas Size Per Tab

  • Set a per-tab canvas size via right-click on the tab; a badge appears in the toolbar when an override is active
  • Canvas size now travels with the document — tiles no longer auto-scale unexpectedly on file open

DiGiCo Integration New

  • DiGiCo OSC sync — sync channel names directly from the console with one tap
  • DiGiCo trigger actions in the automation graph — recall macros and send OSC commands
  • Nested variable sub-menus, name-based channel pickers for all channel types, and Brand/Model split in console settings

YouTube Live Stream Monitor Beta

  • New module to display live broadcast stats on your dashboard
  • Broadcast picker loads faster with a single API call and filters out ended streams
  • Previously-selected broadcasts are preserved in the picker even if not in the current results

Fixes & Improvements

  • Automation graph: Node deletion now supports Undo; the floating Delete button now works in graph mode; help messages when a node can't be added include a clear title and explanation
  • Shure module: Respects the global live mode toggle — shows a "Live data paused" banner and placeholder values when live mode is off
  • Thumbnails moved to ~/Library/Caches/Relay/thumbnails/ to keep project folders tidy
  • Fixed spurious unsaved-changes dialogs when opening files into a blank document or on launch with a startup file
  • Fixed new dashboard sheet not applying the selected canvas size
  • System CPU usage reading is now significantly more accurate
  • Various DiGiCo channel token, icon, and layout fixes
