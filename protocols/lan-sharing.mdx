Relay can share dashboard tabs with other devices on the same local network. There are two main modes: browser view-only links and Relay-to-Relay sharing.

## Browser view-only

Browser view-only creates a stable local URL that mirrors the currently open tab on the source Mac.

1. Open `Relay > Settings > LAN`.
2. Enable browser view-only.
3. Confirm the port.
4. Copy the link and open it on another device on the same network.

## Relay-to-Relay sharing

Relay-to-Relay sharing lets other Relay clients discover, mirror, and import shared tabs.

1. Enable LAN sharing.
2. Optionally require pairing.
3. Share the pairing code if pairing is enabled.

## SPL Meter and Live Transcription

The SPL Meter module can log local SPL history in Live Mode when configured with a log folder.

Live Transcription can:

- show live transcript entries
- export transcript text
- support word-trigger automations

## Troubleshooting

If peers or browser links are not reachable, confirm both devices are on the same network, Relay has Local Network permission, and the correct port or pairing code is being used.
