Relay can receive and send MIDI on Mac.

## Enable MIDI receive

1. Open `Relay > Settings`.
2. Select `MIDI`.
3. Turn on global MIDI.
4. Choose all sources or a specific input.
5. Refresh the device list if a device was just connected.

## Use MIDI in Relay

- MIDI Receive triggers in Automation View
- MIDI Send actions in Automation View
- MIDI-based scene recall workflows
- Timecode display workflows

## Troubleshooting

If MIDI triggers do not fire, confirm the correct input source is selected and that the sending device is emitting the message type you expect.
