## The main parts of Relay

Relay is built around a few core concepts:

- **Dashboard** for the overall file
- **Tabs** for separate views or moments in your workflow
- **Canvas** for visual editing
- **Tiles** for layout containers
- **Modules** for the content inside each tile

## Canvas View

Canvas View is where you build and arrange the dashboard.

Use it to:

- Add, move, and resize tiles
- Organize content visually
- Fine-tune spacing and alignment
- Prepare the dashboard before going live

Useful Canvas View commands often include:

- `View > Canvas View`
- Grid snapping
- Guides
- Resize dashboard canvas
- Bringing all tiles back into view when they drift outside the visible area

## Tabs

Tabs let you organize multiple dashboard views in one file.

Common ways to use tabs:

- Different services or events
- Different teams or operators
- Distinct moments in a production flow

Good tab patterns:

- One tab per service or event segment
- One tab for prep and another for live operation
- One tab per operator role if multiple people use the same dashboard file

## Tiles and modules

A tile is the visual container. A module is the thing that does the work inside it.

Examples of modules include:

- Planning Center
- Person
- ProPresenter
- Shure
- SPL Meter
- Live Transcription
- Time
- Document
- Webpage

<Note>One tile can hold one module or multiple modules depending on how you want the content grouped.</Note>

## Adding and editing tiles

Common tile tasks:

1. Add a tile from the toolbar while in Canvas View.
2. Click the tile to select it.
3. Drag to move it.
4. Resize it with the tile controls or resize handles.
5. Open the inspector to adjust appearance and module layout.

You can also duplicate or delete tiles as your layout evolves.

## Working in the inspector

The inspector is where most editing happens after a tile or module is selected.

Use it to:

- Change colors, opacity, padding, and corner radius
- Configure module-specific settings
- Adjust what content is shown
- Refine grouped layouts inside a tile

## Grouping and repeated layouts

If multiple tiles belong together visually, grouping can help keep them organized.

If you are building a repeated pattern, duplicate an existing tile and adjust the copy rather than rebuilding it from scratch.

## Recommended workflow

1. Build structure in Canvas View.
2. Add modules that match the job each tile needs to do.
3. Configure settings in the inspector.
4. Review tab organization.
5. Enter Live Mode for testing.

## Troubleshooting

### Tiles are hard to align

Turn on grid snapping or guides and make the first tile alignment decision carefully. Everything else gets easier after that.

### A tile appears off-screen

Use the command that brings all tiles into the visible canvas.

### I am not sure whether I need a new tile or just another module

Use a new tile when content should move or scale independently. Use another module in the same tile when the content should remain visually grouped.
