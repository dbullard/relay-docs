## What Live Mode is for

Live Mode is the cleaner operating view in Relay. It reduces accidental editing and lets live modules do their job during production.

## Turn it on

- Choose `View > Live Mode`
- Or press `Command-L`

## What changes in Live Mode

- Editing controls are reduced
- The dashboard becomes easier to read at a glance
- Live modules can begin updating
- Supported interactive modules can still be used

Examples of modules that are commonly useful in Live Mode:

- Time
- SPL Meter
- Live Transcription
- Button
- Supported interactive webpage modules

## Recommended live workflow

1. Build and test the layout in Canvas View first.
2. Confirm every important integration is connected.
3. Make sure the correct tab is active.
4. Enter Live Mode before the event starts.
5. Exit Live Mode only when you need to edit layout or module settings.

## What Live Mode does not fix

Live Mode improves the operating experience, but it does not replace missing setup.

If something is blank or stale, the underlying issue is usually one of these:

- The module is not configured
- The connected service has no relevant data
- The device is offline or unreachable
- macOS permissions are not granted
- The selected tab is not the one you expected

<Warning>If a module depends on network access, audio input, or macOS permissions, Live Mode alone will not fix missing data. You still need the underlying connection or permission in place.</Warning>

## Troubleshooting

### A live module is not updating

Check:

- Live Mode is enabled
- The module is configured correctly
- The target service or device is reachable
- Relay has the required permissions

### I still need to click around too much in Live Mode

That usually means the dashboard needs one more editing pass. Simplify the layout, enlarge the most important information, or split the workflow across tabs.
