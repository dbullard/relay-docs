## What Relay is best at

Relay is a live production dashboard app for Mac. It works best when you want one place to see service data, devices, timers, documents, live status, and simple controls during a show or service.

With Relay, you can:

- Build dashboards on a flexible canvas
- Add tiles for planning, wireless, audio, video, text, and utility modules
- Switch into Live Mode when the dashboard is ready for production use
- Use Automation View to connect triggers, actions, and destinations
- Share or mirror dashboard tabs across your local network

## 5-minute setup

1. Open Relay on your Mac.
2. Create a new dashboard or open an existing `.relay` file.
3. Add your first tile.
4. Add one or more modules to that tile.
5. Open `Relay > Settings` and connect the tools you need.
6. Switch to Live Mode when the dashboard is ready to run.

<Note>You do not need to configure every integration before Relay becomes useful. Start with the one workflow you care about most.</Note>

## First things to configure

After Relay opens successfully, the most useful next stop is `Relay > Settings`.

Start there when you need to set up:

- Planning Center
- ProPresenter
- External devices
- OSC or MIDI
- LAN sharing
- Access and permission status

## Recommended first workflow

If you are brand new to Relay, this is a strong starting sequence:

1. Create a new dashboard.
2. Add one or two tiles.
3. Add simple modules like Text, Time, Webpage, or Document.
4. Connect one outside system such as Planning Center.
5. Enter Live Mode and verify the dashboard reads clearly from the distance you expect to use it.

## Dashboard files

Relay dashboards are typically saved as `.relay` files. Older `.pld` files may also be supported for opening existing work.

Useful file actions:

- `File > New Dashboard`
- `File > Open Dashboard...`
- `File > Save Dashboard`
- `File > Save Dashboard As...`

If autosave is enabled for saved dashboards, Relay can write changes back to an existing dashboard file automatically.

## Core terms

- **Dashboard**: The full Relay document.
- **Tab**: A page inside the dashboard.
- **Canvas**: The editing workspace.
- **Tile**: A movable, resizable container on the canvas.
- **Module**: The content inside a tile.
- **Live Mode**: The cleaner operating view used during production.
- **Automation View**: The node-based workspace for triggers and actions.

## Common first questions

### Do I need Relay Pro to start building?

No. You can begin building dashboards on the free plan. Some advanced modules, device settings, and automation features require Relay Pro.

### Should I configure every integration before I build?

Usually no. Most teams move faster by creating a clean starter layout first, then connecting the services or hardware they actually need.

### What if something is blank or not updating?

Check these first:

- The current tab is the one you intended to edit or run
- The module is configured
- The relevant account or device is connected
- Live Mode is enabled when the feature depends on it
- Relay has the permissions it needs
