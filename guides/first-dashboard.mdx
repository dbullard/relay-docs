## Goal

By the end of this guide, you will have a basic dashboard that is easy to read and ready to test in Live Mode.

## Build the first version

1. Create a new dashboard.
2. Add a tile from the toolbar.
3. Place the tile on the canvas.
4. Add a module to the tile.
5. Repeat until you have the key information you need visible.

Good starter modules include:

- Text
- Time
- Webpage
- Document
- Planning Center
- ProPresenter

## Choose a good starter layout

For most teams, a helpful first dashboard includes:

- One large tile for the most important live information
- One or two supporting tiles for timers, notes, or status
- A simple visual hierarchy that can be understood at a glance

If you are not sure where to begin, start with:

- A Text module for reminders or labels
- A Time module for clock visibility
- A Planning Center or ProPresenter module if those systems matter in your workflow
- A Document or Webpage module for supporting reference material

## Arrange the layout

Use the canvas to move and resize tiles until the dashboard feels clean at a glance.

Useful habits:

- Keep the most important information in the largest tiles.
- Group related information together.
- Leave enough spacing so the screen is readable from a distance.
- Use separate tabs for different moments in your workflow.

Helpful canvas tools:

- Grid snapping for consistent alignment
- Guides when you want cleaner spacing
- Duplicate tile for repeated layouts
- Grouping when multiple tiles belong together
- Resize dashboard canvas if the workspace size itself needs to change

## Edit with the inspector

After selecting a tile, use the inspector to:

- Change appearance
- Adjust module settings
- Update content
- Refine layout and spacing

<Tip>If a dashboard feels crowded, split it into multiple tabs instead of trying to fit everything onto one screen.</Tip>

## Add modules with intention

Modules are most useful when each tile has a clear purpose.

Examples:

- Planning and team visibility: Planning Center, Person
- Audio-related monitoring: SPL Meter, Live Transcription
- Playback or presentation status: ProPresenter, Resolume
- Utility and reference content: Text, Image, Document, Webpage, Time

If content needs to move independently, use separate tiles. If content should stay visually grouped, use multiple modules in one tile.

## Test in Live Mode

1. Confirm your integrations are connected.
2. Switch to `View > Live Mode`.
3. Verify that live modules update the way you expect.
4. Return to Canvas View if you need to make changes.

## Save your work

Use these file actions while building:

- `File > Save Dashboard`
- `File > Save Dashboard As...`

If a dashboard already has a file location, Relay can autosave changes back to that file when autosave is enabled in settings.

## Troubleshooting

### I cannot save the dashboard

Check whether:

- There are unsaved changes
- The file location is writable
- You opened a valid Relay dashboard file

### A tile seems missing

If a tile ends up outside the visible area, use the command that brings all tiles back into the canvas.

### The layout looks good in Canvas View but not live

Check:

- Whether the tile sizes still make sense in Live Mode
- Whether the content is readable from the actual operating distance
- Whether the modules you chose are meant to update live
