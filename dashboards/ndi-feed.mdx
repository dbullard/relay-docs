The `NDI Feed` module lets a dashboard tile show a live NDI video source without leaving Relay.

## Add an NDI feed

1. Select a tile.
2. Open the add-module menu.
3. Choose `NDI Feed`.
4. In the inspector, pick an `NDI Source`.

Relay currently supports up to two active NDI modules per tab.

## Choose the right quality

The module offers three quality tiers:

- `Poster`: 1 fps for minimal CPU use
- `Preview`: 15 fps for confidence monitoring
- `Live`: 30 fps for the smoothest view

Use `Preview` for most operator dashboards and `Live` only when you actually need motion to feel immediate.

## Network options

On Mac, each module can use:

- `Auto` network interface selection
- the global preferred NDI interface from `Relay > Settings > NDI`
- a specific network interface for that tile

If needed, leave `Allow NIC fallback` enabled so Relay can recover when the preferred interface is unavailable.

## Audio and overlays

The module can also:

- show or hide the on-tile overlay
- prefer lower latency
- enable audio
- mute audio in the tile

## Troubleshooting

If you cannot find a source:

- Confirm the sender and this Mac are on the same network segment.
- Open `Relay > Settings > NDI` and verify the preferred interface is correct.
- Use `Refresh Sources` in the module settings.

If a feed pauses unexpectedly:

- Make the tab active.
- Resize the tile larger.
- Reduce the tab to two or fewer active NDI modules.
