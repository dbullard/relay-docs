The `DAW Transport` module adds transport control and counter monitoring for supported DAW workflows.

## What it can do

Depending on the DAW profile you choose, Relay can:

- show a counter
- show transport buttons
- send transport commands like play, stop, record, rewind, and fast forward
- read DAW main-counter feedback or MIDI Timecode

Transport control is intended for `Live Mode`.

## Supported profiles

Relay includes profiles for:

- `Pro Tools HUI`
- `Generic HUI`
- additional HUI, MCU, and MTC/MMC profiles in beta-capable builds

## Configure the module

1. Add `DAW Transport` to a tile.
2. Choose the `DAW` profile in the inspector.
3. Select the MIDI input and output ports, or leave them on `Automatic`.
4. Choose the counter source.

Counter source options depend on the selected DAW profile, but can include:

- `DAW Main Counter`
- `MIDI Timecode`
- `DAW Main Counter + MTC`

## Setup notes

Relay includes setup guidance inside the module settings for each DAW profile. For example, `Pro Tools HUI` expects Relay to be assigned as a HUI control surface and to answer the incoming HUI ping on the selected MIDI input.

## Troubleshooting

If the module does not control the DAW:

- Enter `Live Mode`.
- Confirm the correct MIDI ports are selected.
- Refresh MIDI devices if the port was connected recently.
- Recheck the DAW's HUI, MCU, or MTC/MMC setup against the profile help text in Relay.
