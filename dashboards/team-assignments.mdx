Relay `1.1.0` adds dedicated Team Assignments modules so assignment-focused views no longer need to live inside a larger rundown tile.

## Choose the right module

- `PCO Team Assignments`: uses the current tab's Planning Center service, plan, and service time
- `Roster Team Assignments`: uses a shared `People` roster for teams that are not driven by Planning Center

## PCO Team Assignments

Use this module when the tab is already configured for Planning Center.

Before adding it, make sure the tab has:

- a service type
- a plan
- a service time

The module is useful for showing:

- assigned positions
- person names and avatars
- team-based views
- wireless and equipment picks attached to assignments

If you use an `Equipment` roster, Relay can use that data to enrich assignment workflows.

## Roster Team Assignments

Use this module when your workflow is based on Relay rosters instead of Planning Center.

It works best when you first create a shared `People` roster in the Rosters manager, then map columns such as:

- `Name`
- `Position`
- `Team`
- `Notes`

Display options include:

- sorting by roster order, position, person, or team
- grouping by team
- showing person avatars

## When to use this instead of Person or PCO Rundown modules

Use a Team Assignments module when the tile's main purpose is staffing clarity. Use `Person` modules for individual callouts and `PCO Rundown` when you need the broader plan context.

## Troubleshooting

If the module appears empty:

- For `PCO Team Assignments`, confirm the current tab has a service, plan, and time selected.
- For `Roster Team Assignments`, confirm a shared `People` roster exists and contains rows.
- Recheck the mapped columns if names or positions are missing.
