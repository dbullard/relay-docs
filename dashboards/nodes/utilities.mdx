Utility nodes sit between triggers and actions. They help you build complex logic, manage timing, and route signals appropriately.

## Flow Control
- **Delay:** Pauses the signal for a specified amount of time before passing it to the next node.
- **Repeater:** Takes a single incoming signal and fires it multiple times at a set interval.
- **Sequence:** Steps through a list of outputs one at a time each time it receives a trigger.
- **Merge:** Combines multiple incoming trigger signals into a single output path.

## State Management
- **Toggle:** Flips a boolean (on/off) value each time it's triggered.
- **Counter:** Increments or resets a numerical count based on incoming triggers.
- **Latch / Gate:** Holds a signal path open until explicitly released, or acts as a gate that only allows signals through when open.
- **Current Time:** Injects the current system time as a value into your automation flow.
