Automation View is Relay's node-based workspace for making things happen automatically.

## What it connects

- Triggers that start a workflow
- Actions that do something
- Utilities like delays, repeaters, variables, conditionals, toggles, counters, sequences, latches, and merges
- Destinations such as consoles, wireless devices, and ProPresenter actions

## Common trigger types

- OSC receive
- MIDI receive
- Time
- dB threshold
- Wireless status
- Manual trigger
- Word triggers from live transcription
- App State Trigger
- PCO Plan Updated

## Common action types

- Show notification
- LAN notification
- OSC send
- MIDI send
- ProPresenter action
- Send to supported consoles or wireless destinations
- HTTP Request
- Smart Light Control

## Best practices

- Start with one trigger and one action
- Test one path at a time
- Validate cooldowns and repeatability before using a flow live
- Treat beta-gated graph features carefully
