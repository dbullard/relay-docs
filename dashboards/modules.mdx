Modules are what give tiles meaning. Each module either displays information, pulls in live data, or provides a control you use during an event.

## Adding a module

1. Select a tile.
2. Open the add-module menu.
3. Choose a module.
4. Configure it in the inspector.

You can add more than one module to the same tile when the content belongs together visually.

## Common module groups

### People and planning

- Planning Center
- PCO Team Assignments
- Roster Team Assignments
- Person

### Wireless

- Shure Overview
- Shure
- Sennheiser in beta or debug builds

### Audio

- SPL Meter
- Live Transcription
- DAW Transport
- Real-Time Analyzer (RTA)
- Spectrograph

### Video and presentation

- ProPresenter
- NDI Feed

### Utility

- Text
- Image
- Picker
- Document
- Webpage
- Time
- Timecode
- Separator
- Button

## Beta modules

Some modules are still beta-only or beta-sensitive and should be evaluated separately from the main release feature set.

- YouTube Live Stream Monitor is beta-only in the `1.1.1` cycle
- Sennheiser appears only in beta or debug builds
- Shure and Live Transcription remain beta-sensitive in current builds

## Choosing one tile vs. multiple tiles

Use one tile when modules belong together visually. Use separate tiles when content should move, resize, or scale independently on the canvas.

## Pro and beta notes

Some modules require Relay Pro. Some modules also carry beta status in certain builds, especially around YouTube, wireless, NDI, and transcription workflows.
