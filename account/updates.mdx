Keeping Relay up to date helps ensure you have the latest fixes and compatibility improvements.

## What's new in Relay 1.1.1

### Released in 1.1.1

- New home screen with a sidebar, recent files grid, and canvas size picker for new dashboards
- Startup file pinning so a selected file can always open automatically on launch
- Auto-save enabled by default for files that already have a save location, plus a toolbar save-status indicator
- Per-tab canvas size overrides that stay with the document
- DiGiCo improvements for OSC channel-name sync, automation actions, and clearer console setup

### Beta-only in the 1.1.1 cycle

- The **YouTube Live Stream Monitor** remains a beta-only module for now
- Beta builds can expose newer features earlier than the main release feed
- If you are testing YouTube workflows, use the beta changelog and the beta-features guide as the source of truth

## Check for updates manually

1. Open Relay.
2. Choose `Relay > Check for Updates...`.
3. Follow the prompts if an update is available.

## Beta updates

Beta builds use the beta update feed and may receive newer features earlier, but should still be tested carefully before production use.

## Account-aware update notes

Relay `1.1.0` also improves entitlement refresh and account-backed licensing behavior. If an update finishes but Pro features still look locked, open `Relay > Settings > License` and refresh both the direct license state and any signed-in Relay Account entitlements.

## Troubleshooting

If an update fails, make sure Relay is installed in the Applications folder and not still being run directly from a disk image.
