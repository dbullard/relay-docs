Keeping Relay up to date helps ensure you have the latest fixes and compatibility improvements.

## What's new in Relay 1.2

- **Synced Tabs (Pro):** Share one live, editable canvas across every Mac and iPad running Relay on your network, no cloud required.
- **Universal Automation:** Promote any automation graph to run across every tab that needs it, instead of just the tab it was built on.
- **Standard Console Actions:** Automation can directly trigger scene recall, mute, level, and pan on Behringer X32/M32, Yamaha DM7/Rivage, and Allen & Heath consoles — no third-party bridge required.
- **Tile Distribute Tools:** New distribute and grid-distribute controls, including one-click fill-window layouts.

See the [full changelog](/changelog#version-12) for the complete list of improvements and bug fixes in 1.2, and for every earlier release.

### In-app update history

Relay keeps a **What's New** screen with your update history, shown from the home screen at any time. It also pops up automatically the first time you launch Relay after it updates itself, so you don't have to go looking for what changed.

### Beta-only features

Some features, like the **YouTube Live Stream Monitor** module, remain beta-only ahead of a stable release. Beta builds can expose newer features earlier than the main release feed — if you're testing a beta-only workflow, use the [beta changelog](/beta-changelog) and the [beta features guide](/account/beta-features) as the source of truth.

## Check for updates manually

1. Open Relay.
2. Choose `Relay > Check for Updates...`.
3. Follow the prompts if an update is available.

## Beta updates

Beta builds use the beta update feed and may receive newer features earlier, but should still be tested carefully before production use.

## Account-aware update notes

Relay `1.1.0` also improves entitlement refresh and account-backed licensing behavior. If an update finishes but Pro features still look locked, open `Relay > Settings` → <Icon icon="credit-card" /> **Subscription** and refresh both the direct license state and any signed-in Relay Account entitlements.

## Troubleshooting

If an update fails, make sure Relay is installed in the Applications folder and not still being run directly from a disk image.
