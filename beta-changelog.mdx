## Version 1.2 (build 56) <a id="version-12"></a>

#### Relay 1.2 (Beta) — Build 56

New

- **Synced Tabs (Pro).** Share one live, editable dashboard across every Mac and iPad on your network in real time — no cloud required. Device-specific connections (ProPresenter, consoles, Shure/Sennheiser, DAW/MIDI, audio inputs) always stay local to each machine. Hosting requires Relay Pro; joining is free.
- **Universal Automation.** Promote any automation graph to Universal and run it across your whole show instead of one tab.
- **Standard Console Actions.** Automation can trigger scene recall, mute, level, and pan directly on X32/M32, Yamaha DM7/Rivage, and Allen & Heath consoles.
- **Tile Distribute Tools.** Select multiple tiles and arrange them instantly with distribute and grid-distribute controls, including one-click fill-window layouts.

Beta Preview

Ahead of the general release, this build also includes:

- **ProPresenter State trigger.** Fire automations off ProPresenter slide, presentation, message, or timer changes.
- **Smart Light Control.** New automation node to trigger Govee and Philips Hue scenes, color, and brightness.
- **Expanded DAW Transport protocols.** Logic Pro, Reaper (HUI and MCU), and Cubase/Nuendo join Pro Tools HUI and Generic HUI as selectable transport types.

Improved

- Dashboard tiles resize down to 44&times;44pt (previously 160&times;120pt) for denser button layouts.
- Canvas panning, zooming, and tile dragging are noticeably smoother on busy dashboards; trackpad pan/zoom no longer gets captured by scrollable content inside a module.
- Word Trigger nodes support per-rule output ports, so each matched phrase can route to its own downstream action.
- Redesigned button icon picker: a searchable popover across roughly 340 SF Symbols.
- New in-app "What's New" screen with full update history and an auto-popup after updating.
- Real Quit button on the home screen sidebar; Quit/Close now respond even while a sheet is open.
- Settings polish: Save/Cancel on the General tab, alphabetized device lists, no more flickering numeric fields.
- RTA/Spectrograph tiles show a clear empty state instead of a blank tile when no input is selected.
- New opt-in consent screen for diagnostics and crash reporting.
- CSV/Excel roster import built directly into the Rosters Manager.

Fixed

- Shure wireless receivers now reconnect automatically after a network drop, showing "Reconnecting" instead of silently sitting offline — previously required toggling Live Mode twice.
- "Auto" transport mode for Shure ANX4/ADTD/ADTQ now actually detects the best connection type instead of defaulting to one.
- Fixed Overview polling adding redundant traffic that could destabilize some receivers' connections.
- Fixed Live Mode unexpectedly exiting when tapping two different interactive tiles in quick succession.
- Fixed dashboard resize handles intermittently failing to respond, showing the wrong cursor, or falling through to a move-drag.
- Fixed multi-tile group resizing occasionally snapping a follower tile to the wrong height on release.
- Fixed dashboard edits being silently dropped when made immediately after reordering or removing a tab.
- Fixed a crash and hang when upgrading to Relay Pro from the home screen.
- Fixed a crash when switching tabs while an automation graph was open.
- Fixed a reappeared horizontal scrollbar under the tab strip and other horizontal lists.

## Version 1.1.4 (build 55) <a id="version-114"></a>

#### Relay 1.1.4 (Beta) — Build 55

New

- **Standard console actions.** Automation can now send common audio-console commands like scene recall, channel mute, level, and pan on supported X32/M32 and Yamaha DM7/Rivage systems.
- **More beta audio console integrations.** Added Behringer WING support with network discovery and Avid VENUE S6L support with VENUE OSC connection settings.

Improved

- **Smoother canvas editing.** Pan, zoom, resize, distribute, and dragged-tile rendering are more stable, with tab and tile edits resolved by stable identities instead of stale positions.
- **Better device recovery and setup.** Shure devices now show reconnecting status and recover more cleanly, dead console connections are rebuilt before sending, and external device type lists are alphabetized for easier scanning.

Fixed

- Fixed several strict-concurrency and transport-state issues across helper, OSC, shape, and integration code paths.
- Fixed remaining tab mutations that could target a stale position instead of the intended tab.
- Fixed Sennheiser wireless using a different category icon than Shure wireless in external device settings.

#### Relay 1.1.4 (Beta) — Build 54

Improved

- **"Auto" transport mode for ANX4/ADTD/ADTQ now actually auto-detects.** Previously Auto silently always used the older connection method — you had to manually pick "TCP Only" to get Build 53's improvements. Now Auto briefly checks whether your device supports the newer protocol and switches automatically.

Fixed

- Fixed a bug where, once Auto had settled on the newer connection type, Relay would needlessly disconnect and re-check it on every reconnect attempt.

#### Relay 1.1.4 (Beta) — Builds 49–53

Highlights

- **Expanded Shure support.** Added ANX4, ADTD, and ADTQ support with TCP control, automatic licensed channel-count detection, RSSI fixes, and correct licensed channel counts across automation, Shure Summary, Planning Center team assignments, and tile editing.
- **Synced Tabs.** Keep a tab live and editable across your devices on the same network — different from Mirroring, which is view-only. Devices must approve each other before syncing or mirroring can start.
- **Reworked Button module** with more buttons per module and a much bigger icon library.
- **Shure Summary module** gained card/list display, sizes, per-channel person names, and a choice of signal light/meter/hidden for live audio activity.
- **Tab Settings General page** for Canvas Size, Sync This Tab, and a live list of who's viewing.
- **CSV/Excel roster import and opt-in diagnostics**, plus multi-select canvas tools and broader crash-reporting controls.
- **ProPresenter State trigger (beta)** for automation, a distinct Paused state for DAW Transport, and a Reconnect option for sync devices that fail authentication.
- Broad reliability fixes across icon search, device discovery/reconnect, Sync/Mirror settings, dashboard guides, and numeric settings fields.

## Version 1.1.3 (build 46) <a id="version-11346"></a>

## What's New in Relay

### New Features

- **Global Transcription Inputs:** Transcription inputs are now managed globally in their own dedicated tab alongside other audio inputs.
- **Redesigned Audio Settings:** The Audio Inputs configuration now features a sleek sidebar-and-detail split layout, making it much easier to manage your devices.
- **Word Substitutions:** Easily filter or replace specific words on the fly during live transcriptions.
- **Profanity Controls:** Profanity masking and removal controls are now built directly into the individual input settings.
- **Per-Input Audio Settings:** Fine-tune auto-gain sensitivity and engine preference for each individual audio input from a dedicated settings panel.

### Improvements

- Existing transcription settings will automatically migrate to the new global system on your next launch.
- Level meters have been relocated directly into the individual detail views for cleaner organization.

### Bug Fixes

- Fixed an issue where SPL Level logging could silently fail when saving to protected folders like Desktop, Documents, or Downloads. Relay will now correctly show an error banner if it needs you to grant folder access permissions.

## Version 1.1.2 (build 44) <a id="version-11244"></a>

### What's New

10 New Automation Nodes

The automation graph gets a big expansion. New nodes you can drop onto the canvas:

- **HTTP Request** — trigger any web endpoint or API from an automation
- **Set Variable** — store and reuse values across your automation flow
- **App State Trigger** — fire automations on app launch, live mode toggle, or tab switch
- **PCO Plan Updated** — trigger when your Planning Center plan changes, with a live item picker to filter exactly what you care about
- **Toggle** — flip a value on/off each time it's triggered
- **Counter** — increment or reset a count
- **Sequence** — step through a list of outputs one at a time
- **Latch/Gate** — hold a signal open until explicitly released
- **Merge** — combine multiple signals into one
- **Current Time** — use the current time as a value in your flow

Console Node Improvements

- You can now add **multiple graph nodes for the same console**, useful when you need to send different trigger actions to the same device from different parts of your graph
- **Trigger bindings** have moved from the trigger node to the console node, making it much clearer which console handles which trigger action
- Console nodes now show a **capability mismatch warning** if you connect a source that the console doesn't support

Live Mode Button

- The live mode button is now its own standalone control in the toolbar, no longer grouped with other buttons

Network Pairs Indicator

- The connected network pairs pill has moved into the System Status overlay, keeping it alongside CPU, memory, OSC, and MIDI activity where it belongs

Smart Light Control Beta

- New automation node to control smart lights directly from your dashboard automations — set colors, brightness, and scenes as part of any trigger flow

---

### Fixes & Improvements

- **PCO Auto-Advance** redesigned as a weekly checkpoint coordinator for more reliable and predictable behavior
- **ProPresenter** quick-add devices directly from discovered devices on your network; settings UI polished throughout
- All 10 new automation nodes support duplicate and remove actions
- Latch/Gate, Toggle, and Sequence node UI polished
- Console nodes now correctly name and distinguish between trigger nodes in the binding picker
- Console node state is properly cleaned up on deletion and correctly copied on duplication
- Node collapse state now persists when switching between automation modes
- Significant automation graph performance improvements — cache rebuilds now happen off the main thread, reducing UI stutter when opening large dashboards
- Various automation node stability fixes
