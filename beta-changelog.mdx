## Version 1.1.4 (build 48) <a id="version-114"></a>

#### Relay 1.1.4 (Beta)

New

- **Synced Tabs.** A whole new way to share your work across devices — pick a tab and keep it live-synced with your other Macs and iPads on the same network. Edit it anywhere and everyone sees the change instantly. This is different from Mirroring, which only lets you view another device's screen; Synced Tabs are fully editable and stay in step automatically, even if a device drops offline and reconnects later. Each device also keeps its own hardware and connection settings (ProPresenter, Shure, Sennheiser, NDI, audio inputs, etc.) — syncing a tab won't overwrite them with another device's setup.
- **Reworked Button module.** Fit more buttons per module, plus a wider set of new icons to choose from, a bigger icon size range, and a one-click reset back to the default size.
- **Approve devices before they connect.** When another device wants to sync or mirror with you, you'll now get a clear approval prompt — nothing connects without your say-so. You can also forget a device later if you no longer want it connected.
- **Shure Summary module updates.** Choose card or list display, pick small/medium/large card sizes, and assign a person's name to each channel so summaries read at a glance.

Improved

- Sync and Mirror settings are now organized into one clean page, so it's easier to see which devices are connected and reconnect with a single click.
- Shure wireless devices run lighter on your Mac, especially during longer shows with lots of channels active.
- Still working on full ANX4 and ADTD support — more to come in an upcoming beta.

Fixed

- Button icons and sizing changes now apply instantly and stick, even when you're adjusting things quickly.
- Fixed duplicate results showing up when searching for icons.
- Devices on your network are now found reliably, and reconnect faster when a synced tab's host comes back online.
- Toolbar labels for Sync and Mirror no longer get cut off on Mac.
- Selecting a mirrored tab now properly starts the pairing process instead of getting stuck.
- Planning Center service and plan selections on synced tabs no longer get cleared if a device hasn't finished loading Planning Center data yet.
- Cleaned up how Relay manages OSC network connections so it doesn't accumulate idle ones during long sessions.

## Version 1.1.3 (build 46) <a id="version-11346"></a>

## What's New in Relay

### New Features

- **Global Transcription Inputs:** Transcription inputs are now managed globally in their own dedicated tab alongside other audio inputs.
- **Redesigned Audio Settings:** The Audio Inputs configuration now features a sleek sidebar-and-detail split layout, making it much easier to manage your devices.
- **Word Substitutions:** Easily filter or replace specific words on the fly during live transcriptions.
- **Profanity Controls:** Profanity masking and removal controls are now built directly into the individual input settings.
- **Per-Input Audio Settings:** Fine-tune auto-gain sensitivity and engine preference for each individual audio input from a dedicated settings panel.

### Improvements

- Existing transcription settings will automatically migrate to the new global system on your next launch.
- Level meters have been relocated directly into the individual detail views for cleaner organization.

### Bug Fixes

- Fixed an issue where SPL Level logging could silently fail when saving to protected folders like Desktop, Documents, or Downloads. Relay will now correctly show an error banner if it needs you to grant folder access permissions.

## Version 1.1.2 (build 44) <a id="version-11244"></a>

### What's New

10 New Automation Nodes

The automation graph gets a big expansion. New nodes you can drop onto the canvas:

- **HTTP Request** — trigger any web endpoint or API from an automation
- **Set Variable** — store and reuse values across your automation flow
- **App State Trigger** — fire automations on app launch, live mode toggle, or tab switch
- **PCO Plan Updated** — trigger when your Planning Center plan changes, with a live item picker to filter exactly what you care about
- **Toggle** — flip a value on/off each time it's triggered
- **Counter** — increment or reset a count
- **Sequence** — step through a list of outputs one at a time
- **Latch/Gate** — hold a signal open until explicitly released
- **Merge** — combine multiple signals into one
- **Current Time** — use the current time as a value in your flow

Console Node Improvements

- You can now add **multiple graph nodes for the same console**, useful when you need to send different trigger actions to the same device from different parts of your graph
- **Trigger bindings** have moved from the trigger node to the console node, making it much clearer which console handles which trigger action
- Console nodes now show a **capability mismatch warning** if you connect a source that the console doesn't support

Live Mode Button

- The live mode button is now its own standalone control in the toolbar, no longer grouped with other buttons

Network Pairs Indicator

- The connected network pairs pill has moved into the System Status overlay, keeping it alongside CPU, memory, OSC, and MIDI activity where it belongs

Smart Light Control Beta

- New automation node to control smart lights directly from your dashboard automations — set colors, brightness, and scenes as part of any trigger flow

---

### Fixes & Improvements

- **PCO Auto-Advance** redesigned as a weekly checkpoint coordinator for more reliable and predictable behavior
- **ProPresenter** quick-add devices directly from discovered devices on your network; settings UI polished throughout
- All 10 new automation nodes support duplicate and remove actions
- Latch/Gate, Toggle, and Sequence node UI polished
- Console nodes now correctly name and distinguish between trigger nodes in the binding picker
- Console node state is properly cleaned up on deletion and correctly copied on duplication
- Node collapse state now persists when switching between automation modes
- Significant automation graph performance improvements — cache rebuilds now happen off the main thread, reducing UI stutter when opening large dashboards
- Various automation node stability fixes

## Version 1.1.1 (build 43) <a id="version-11143"></a>

### New

- **Home Screen & Launch Experience**
  - New home screen with a sidebar, recent files grid, and canvas size picker when creating a new dashboard.
  - Startup file: right-click any file to pin it as always-open on launch. This bypasses the home screen and save dialog automatically, and pinned files show a blue pin badge in the grid.
- **Auto-Save**
  - Saving/Saved status indicator in the toolbar.
  - Auto-save is now enabled by default for files with a known save location.
  - First-time auto-save users see a one-time modal with an inline toggle to disable it.
- **Canvas Size Per Tab**
  - Set a per-tab canvas size via right-click on the tab. A badge appears in the toolbar when an override is active.
  - Canvas size now travels with the document, so tiles no longer auto-scale unexpectedly on file open.
- **DiGiCo Integration**
  - DiGiCo OSC sync lets you sync channel names directly from the console with one tap.
  - DiGiCo trigger actions are now available in the automation graph to recall macros and send OSC commands.
  - Added nested variable sub-menus, name-based channel pickers for all channel types, and a Brand/Model split in console settings.
- **YouTube Live Stream Monitor (Beta)**
  - New module to display live broadcast stats on your dashboard.
  - The broadcast picker now loads faster with a single API call and filters out ended streams.
  - Previously-selected broadcasts are preserved in the picker even if they are not in the current results.

### Improved

- Automation graph node deletion now supports Undo.
- The floating Delete button now works in graph mode.
- Help messages when a node can't be added now include a clear title and explanation.
- The Shure module now respects the global live mode toggle and shows a "Live data paused" banner with placeholder values when live mode is off.
- Thumbnails now live in `~/Library/Caches/Relay/thumbnails/` to keep project folders tidy.
- System CPU usage reading is now significantly more accurate.

### Fixed

- Fixed spurious unsaved-changes dialogs when opening files into a blank document or on launch with a startup file.
- Fixed the new dashboard sheet so it correctly applies the selected canvas size.
- Fixed various DiGiCo channel token, icon, and layout issues.
