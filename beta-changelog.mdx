## Version 1.1.0 <a id="version-110"></a>

### New

- Added a dedicated Roster Team Assignments module and expanded Planning Center team assignment workflows.
- Added a new DAW Transport module for sending and monitoring transport-style controls in dashboards.
- Added a basic Relay test target.

### Improved

- Improved Planning Center assignment tiles with richer wireless assignment handling, roster-backed assignment options, role defaults, and cleaner persistence.
- Improved Shure Wireless live telemetry, including better RF, battery, transmitter presence, mute, audio-level, and channel-name handling across supported receiver models.
- Added large-graph performance mode in Automation Graph view, with simplified node cards for busy graphs and more diagnostic coverage for graph layout and undo performance.
- Reworked External Control settings into a combined MIDI/OSC monitor page with live message status, source selection, counters, and setup guidance.
- Improved dashboard tile resizing, canvas persistence, graph collision handling, and live/flip rendering behavior.
- Expanded diagnostics exports with performance summaries, event counters, active canvas composition, active graph composition, and more runtime context.

### Fixed

- Fixed pan/zoom issues.
- Fixed drag resize issues.
- Fixed tutorial view issues.
