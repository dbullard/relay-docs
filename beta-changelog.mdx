## Version 1.1.1 (build 43) <a id="version-11143"></a>

<h2 style="font-size:1rem;font-weight:600;text-transform:uppercase;letter-spacing:0.05em;color:#555;margin:0 0 12px;">What's New</h2>

<p style="font-size:1.05rem;font-weight:600;margin:20px 0 6px;">Home Screen &amp; Launch Experience</p>
<ul style="margin:0 0 16px;padding-left:20px;line-height:1.6;">
  <li>New home screen with a sidebar, recent files grid, and canvas size picker when creating a new dashboard</li>
  <li><strong>Startup file</strong> — right-click any file to pin it as always-open on launch; bypasses the home screen and save dialog automatically. Pinned files show a blue pin badge in the grid</li>
</ul>

<p style="font-size:1.05rem;font-weight:600;margin:20px 0 6px;">Auto-Save</p>
<ul style="margin:0 0 16px;padding-left:20px;line-height:1.6;">
  <li>Saving/Saved status indicator in the toolbar</li>
  <li>Auto-save now enabled by default for files with a known save location</li>
  <li>First-time auto-save users see a one-time modal with an inline toggle to disable it</li>
</ul>

<p style="font-size:1.05rem;font-weight:600;margin:20px 0 6px;">Canvas Size Per Tab</p>
<ul style="margin:0 0 16px;padding-left:20px;line-height:1.6;">
  <li>Set a per-tab canvas size via right-click on the tab; a badge appears in the toolbar when an override is active</li>
  <li>Canvas size now travels with the document — tiles no longer auto-scale unexpectedly on file open</li>
</ul>

<p style="font-size:1.05rem;font-weight:600;margin:20px 0 6px;">DiGiCo Integration <span style="display:inline-block;font-size:0.7rem;font-weight:600;text-transform:uppercase;letter-spacing:0.04em;padding:2px 7px;border-radius:20px;background:#dbeafe;color:#1d4ed8;margin-left:6px;">New</span></p>
<ul style="margin:0 0 16px;padding-left:20px;line-height:1.6;">
  <li><strong>DiGiCo OSC sync</strong> — sync channel names directly from the console with one tap</li>
  <li><strong>DiGiCo trigger actions</strong> in the automation graph — recall macros and send OSC commands</li>
  <li>Nested variable sub-menus, name-based channel pickers for all channel types, and Brand/Model split in console settings</li>
</ul>

<p style="font-size:1.05rem;font-weight:600;margin:20px 0 6px;">YouTube Live Stream Monitor <span style="display:inline-block;font-size:0.7rem;font-weight:600;text-transform:uppercase;letter-spacing:0.04em;padding:2px 7px;border-radius:20px;background:#fef9c3;color:#854d0e;margin-left:6px;">Beta</span></p>
<ul style="margin:0 0 16px;padding-left:20px;line-height:1.6;">
  <li>New module to display live broadcast stats on your dashboard</li>
  <li>Broadcast picker loads faster with a single API call and filters out ended streams</li>
  <li>Previously-selected broadcasts are preserved in the picker even if not in the current results</li>
</ul>

<hr style="border:none;border-top:1px solid #e5e5e5;margin:24px 0;" />

<h2 style="font-size:1rem;font-weight:600;text-transform:uppercase;letter-spacing:0.05em;color:#555;margin:0 0 12px;">Fixes &amp; Improvements</h2>
<ul style="margin:0;padding-left:20px;line-height:1.6;">
  <li><strong>Automation graph:</strong> Node deletion now supports Undo; the floating Delete button now works in graph mode; help messages when a node can't be added include a clear title and explanation</li>
  <li><strong>Shure module:</strong> Respects the global live mode toggle — shows a "Live data paused" banner and placeholder values when live mode is off</li>
  <li>Thumbnails moved to <code style="font-family:monospace;font-size:0.85em;background:#f3f4f6;padding:1px 5px;border-radius:4px;">~/Library/Caches/Relay/thumbnails/</code> to keep project folders tidy</li>
  <li>Fixed spurious unsaved-changes dialogs when opening files into a blank document or on launch with a startup file</li>
  <li>Fixed new dashboard sheet not applying the selected canvas size</li>
  <li>System CPU usage reading is now significantly more accurate</li>
  <li>Various DiGiCo channel token, icon, and layout fixes</li>
</ul>

## Version 1.1.0 (build 42) <a id="version-11042"></a>

<h1>A BIG UPDATE</h1>

<h2>New</h2>

<ul>

  <li>Added new NDI support with video monitoring capabilities for Relay dashboards.</li>

  <li>Added a new Shure Summary module for simplified monitoring of wireless microphones and IEM systems.</li>

  <li>Added a new DAW Transport module for monitoring and controlling supported DAW transport workflows.</li>

  <li>Added a dedicated Roster Team Assignments module to use with new Roster types</li>
  <li>New Planning Center Team Assignment module that will allow for more formatting of teams and assignments in addtion to assigning stored mics, IEMs, and equipment from the new Equipment Roster type.</li>

  <li>Continued development work toward future iPad support.</li>

</ul>

<h2>Improved</h2>

<ul>

    <li>Improved dedicated Roster editing view accessible from the toolbar. 3 new Roster types that will allow you to use your rosters across all tabs.</li>
  <li>Improved dashboard editing, canvas behavior, tile resizing, and Live Mode performance.</li>

  <li>Improved Automation View performance and handling for larger graphs and complex workflows.</li>

  <li>Improved Planning Center assignments with richer wireless device mapping and roster workflows.</li>

  <li>Improved Shure wireless monitoring with enhanced RF, battery, mute, audio, and transmitter reporting.</li>

  <li>Improved NDI performance, reconnect behavior, diagnostics, settings, and video pipeline efficiency.</li>

  <li>Reworked External Controls with a combined MIDI and OSC monitor view, live activity tracking, and setup guidance.</li>

  <li>Expanded diagnostics with additional performance, dashboard, automation, and runtime information.</li>



</ul>

<h2>Fixed</h2>

<ul>

  <li>Fixed multiple Planning Center stability, refresh, and authentication issues.</li>


  <li>Fixed dashboard rendering, graph behavior, and Live Mode performance issues.</li>

  <li>Fixed automation view rendering and efficiency issues.</li>

  <li>Fixed several crash paths and improved overall application stability.</li>

  <li>Improved security handling across integrations and credential storage.</li>

</ul>

## Version 1.1.0 <a id="version-110"></a>

### New

- Added a dedicated Roster Team Assignments module and expanded Planning Center team assignment workflows.
- Added a new DAW Transport module for sending and monitoring transport-style controls in dashboards.
- Added a basic Relay test target.

### Improved

- Improved Planning Center assignment tiles with richer wireless assignment handling, roster-backed assignment options, role defaults, and cleaner persistence.
- Improved Shure Wireless live telemetry, including better RF, battery, transmitter presence, mute, audio-level, and channel-name handling across supported receiver models.
- Added large-graph performance mode in Automation Graph view, with simplified node cards for busy graphs and more diagnostic coverage for graph layout and undo performance.
- Reworked External Control settings into a combined MIDI/OSC monitor page with live message status, source selection, counters, and setup guidance.
- Improved dashboard tile resizing, canvas persistence, graph collision handling, and live/flip rendering behavior.
- Expanded diagnostics exports with performance summaries, event counters, active canvas composition, active graph composition, and more runtime context.

### Fixed

- Fixed pan/zoom issues.
- Fixed drag resize issues.
- Fixed tutorial view issues.
